📈 Explicación de las Métricas

🎯 Accuracy (Exactitud)

Porcentaje de predicciones correctas sobre el total de análisis realizados.

Fórmula: (VP + VN) / Total

📊 Precision (Precisión)

De las noticias marcadas como falsas, cuántas realmente son falsas.

Fórmula: VP / (VP + FP)

🔍 Recall (Sensibilidad)

De las noticias realmente falsas, cuántas logramos detectar.

Fórmula: VP / (VP + FN)

⭐ F1-Score

Media armónica entre Precision y Recall para balancear ambas métricas.

Fórmula: 2 × (Precision × Recall) / (Precision + Recall)
